Installation has moved to README.md and docs/nix-migration.md.

This repository now uses a pinned Nix flake with standalone Home Manager on an
existing Linux distribution. Review nix/hosts.nix and the documented assumptions
before explicitly installing Nix, building, backing up conflicts, or activating.

The old sysdef executable is retired. modules/, providers/ and sysdef-src/ remain
historical implementation/test references, not installation instructions.
Never run the legacy writer and Home Manager against the same files concurrently.

No bootstrap script installs Nix, invokes sudo, changes native services, or
activates the home automatically.
